# SincerelySea

Aplikasi komunitas dan commerce premium untuk tas kulit sapi SincerelySea. Bukan jejaring sosial generik dan bukan toko biasa.

| | |
|---|---|
| Platform | Android dan iOS |
| Stack | Flutter + Firebase |
| Repositori | https://github.com/ekakoel/app-sincerelysea |
| Desain | https://www.figma.com/design/op6iQBv7uUCAWJIHoUKrJA |

## Status

Repositori sudah terhubung. Kode aplikasi belum dimulai.

Foto stok pada eksplorasi desain bukan foto produk resmi. Harga di desain hanya tampilan; harga nyata dihitung di server. Kepemilikan produk hanya dari pesanan yang memenuhi syarat atau verifikasi yang diotorisasi.

## Commit

Setiap perubahan kode aplikasi wajib di-commit dan di-push ke repositori ini.

- Branch default: `main`
- Jangan force-push ke `main`
- Jangan commit rahasia (service account, keystore, `.env`, `google-services.json`, `GoogleService-Info.plist`)
- Pesan commit singkat, dalam bahasa Inggris, dan menjelaskan perubahannya
